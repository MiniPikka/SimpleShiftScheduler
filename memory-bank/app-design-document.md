# 倒班助手 App 设计文档

## 1. 概述

**应用名称**：倒班助手
**平台**：Android
**功能简介**：
用于帮助用户管理和查看倒班信息，支持周期设置、班组管理、日历展示及统计功能。

---

## 2. 主要功能模块

### 2.1 首页

**功能**：展示今日倒班信息、进度和关键指标。

**界面结构**：

```
┌──────────────────────────────────────┐
│  [班组选择: 一值 ▼]                   │  TeamDropdown
├──────────────────────────────────────┤
│  早上好，一值                          │  GreetingHeader
│  2026年5月13日 星期三                  │
├──────────────────────────────────────┤
│  ┌──────────────────────────────┐    │
│  │       夜                      │    │  TodayShiftCard
│  │    (紫色大字)                  │    │  (按班次颜色着色)
│  │  进度: 10/42                  │    │
│  │  距休 2 天                    │    │
│  └──────────────────────────────┘    │
├──────────────────────────────────────┤
│  ┌────────┬────────┬────────┐        │
│  │ 本月上班│ 连续上班│ 距休班  │        │  StatsGrid
│  │  10天  │  3天   │  2天   │        │  三宫格指标
│  └────────┴────────┴────────┘        │
├──────────────────────────────────────┤
│   📅 日历  │  ⏰ 提醒  │  ⚙️ 设置   │  QuickActionsRow
├──────────────────────────────────────┤
│     休息是为了走更远的路                │  MotivationFooter
└──────────────────────────────────────┘
```

**界面元素**：

* 班组切换下拉框（保持不变）
* 时段问候头部（早上好/下午好/晚上好/夜班辛苦了 + 班组名）
* 今日日期与星期（本地化可读）
* 今日班次主卡片（横向布局：左侧颜色强调条 + 圆形班次徽章白字 + 标题/距休徽章 + LinearProgressIndicator 进度条）
* 三宫格指标卡片（本月上班天数、连续上班天数、距离休班天数）
* 快捷操作按钮行（日历、提醒、设置）
* 底部随机励志文案
* 班次展示文案：`早/中/休/夜/学`
* 周期说明：一个周期 42 天，班组 6 个值

### 2.2 倒班日历

**功能**：独立页面，通过首页"📅 日历"按钮跳转进入。按日历展示本月倒班情况，可切换班组并统计班次数量。

**界面结构**：
- 顶部 TopAppBar（返回箭头 + 标题"倒班日历"）
- 班组下拉框
- 月份导航栏（上月/下月 + 今天按钮 + 统计按钮）

**界面元素**：

* **7×7 日历表**：

  * 第一行显示周日到周六
  * 其余行显示当前月日期及补全的前月/下月日期
  * 每个格子包含两行：

    1. 日期
    2. 班次类型（早、中、休、夜、学习班）
* **左上角班组切换下拉框**：用于切换不同班组
* **右上角统计按钮**：统计当前班组在当月早、中、休、夜、学习班的天数

---

### 2.3 倒班规则设置

**功能**：用户自定义倒班周期、班次规则及默认班组。

**界面元素**：

* 周期长度设置
* 每一天班次设置
* 默认班组选择
* 保存并应用按钮

**操作流程**：

1. 用户选择周期长度
2. 设置每天对应班次
3. 选择默认班组
4. 点击保存，系统应用规则

---

### 2.4 日历提醒

**功能**：为每个班次类型设置独立的提醒时间，通过系统日历日程实现。

**界面元素**：

* 提醒设置在设置页"倒班规则设置"中，位于班组选择下方
* 每个班次类型（早/中/休/夜/学）一行，显示当前提醒时间或"未设置"
* 点击行弹出时间选择对话框（时/分输入）
* 已设置提醒的班次可点击"关闭此班次提醒"删除

**提醒策略**：

* 使用 Android Calendar Provider（`CalendarContract`）写入设备本地日历日程
* 每次设置变更后自动同步未来 365 天（一整年）的日历日程
* 日程持久化在系统日历数据库，设备重启自动恢复
* 应用回到前台时重新同步（处理时区变更）
* 使用默认班组计算班次日期
* 每个日程设置准时提醒（`METHOD_ALERT`），系统自动弹出通知
* 使用本地日历账户（`ACCOUNT_TYPE_LOCAL`），日程不依赖 Google 账户、不同步云端

**跨品牌兼容性**：

* Calendar Provider 是 AOSP 标准 API（API 14+），所有 Android 品牌必须支持
* 小米 MIUI、华为 EMUI/HarmonyOS、OPPO ColorOS、Vivo OriginOS、三星、原生 Android 全兼容

**权限需求**：

* `READ_CALENDAR`：读取系统日历（查询现有日程）
* `WRITE_CALENDAR`：写入/修改系统日历日程

### 2.5 桌面小组件

**功能**：在设备桌面显示今日班次信息，无需打开 App 即可查看。

**界面元素**：

```
┌──────────────────────────────────────┐
│  ┌───────┐                           │
│  │  早   │  一值          距休 2天   │
│  │ 白字  │  第 10/42 天              │
│  └───────┘                           │
│  2026年5月14日 星期三                 │
└──────────────────────────────────────┘
```

* 班组名称
* 当前日期（本地化可读）
* 今日班次（圆角徽章 + 彩色背景白字：早=橙、中=蓝、休=绿、夜=紫、学=黄）
* 距休天数（=0 显示绿色"休息日"，>0 显示"距休 X天"）
* 周期进度（纯文字"第 X/Y 天"，Glance 不支持进度条组件）
* Widget 尺寸：4×1（`targetCellWidth=4`, `targetCellHeight=1`）

**交互**：

* 点击 Widget 任意位置 → 打开 App 首页
* Widget 每 1 小时自动刷新
* App 内修改设置后 Widget 立即更新

**技术方案**：

* 使用 Jetpack Glance 框架（Compose 式 Widget API）
* 直接从 DataStore 读取倒班配置，调用 domain 层 `computeWidgetShiftData()` 计算今日数据（含 `daysUntilNextRest()`）
* 进度使用纯文字"第 X/Y 天"（Glance 不支持 `LinearProgressIndicator`、`fillMaxWidth(fraction)`、`defaultWeight()` 加权比例）
* 徽章使用 `Box` + `cornerRadius(12.dp)` + `background(accentColor)`（Glance 无 `CircleShape`）
* 无需额外后台服务，利用系统 Widget 更新机制

## 3. 数据结构设计（简要）

* **班组信息**

```json
{
  "group_id": 1,
  "name": "班组1",
  "shift_cycle": ["早","早","中","中","休","夜","夜", ...] // 42天
}
```

* **日历数据**

```json
{
  "date": "2026-04-26",
  "shift": "早"
}
```

* **统计数据**

```json
{
  "early": 10,
  "mid": 8,
  "rest": 12,
  "night": 8,
  "study": 4
}
```

* **闹钟设置**

```json
{
  "MORNING": "06:00",
  "AFTERNOON": "14:00",
  "REST": null,
  "NIGHT": "22:00",
  "STUDY": null
}
```

## 5. 其他说明

* 支持多班组管理
* 支持自定义倒班规则
* 支持周期循环与跨月显示
* 提供当月班次统计功能
* 首页日期展示要求为“本地化可读”即可（不强制固定格式）
* 日期计算使用设备本地时区，基于 `LocalDate.now()` 即时生效
